## 1. Цель проекта

Собрать многостраничный **мультиязычный** лэндинг-портфолио по макету из Miro-доски.

### Расширенный контекст (добавлено 2026-05-30)
- Лэндинг-портфолио — это **первый этап**. Живёт на **субдомене** основного домена.
- На **основном домене** в перспективе — **образовательная видеоплатформа** (обучающие
  видеоуроки/курсы). Это отдельный крупный продукт со своими требованиями (аккаунты, оплата,
  стриминг, прогресс) — пока НЕ строим, только резервируем домен и не загоняем себя в угол.
- Триггер вопроса о видео: в портфолио-кейсах есть **видео** (рекламные ролики, скринкасты),
  сейчас лежат «на диске». Нужно решить, как их физически отдавать.
- Требование к будущей платформе: **защита видео от скачивания** — «невозможность собрать
  из стрима исходное видео» (= по сути нужен DRM, см. раздел про видео).
- Приоритеты: **SEO** и **простота добавления контента**.
- **Открыто:** найти доменное имя.

Исходно планировалось также спарсить старый проект на Tilda (как источник контента/вёрстки), но он сейчас недоступен — см. раздел 3.

### Про будущую видеоплатформу (зафиксировано на будущее, НЕ делаем сейчас)
- Требование «нельзя собрать исходник из стрима» = нужен **настоящий DRM** (Widevine/FairPlay/PlayReady).
  Без DRM HLS-сегменты склеиваются обратно. AES-128 HLS — лишь «защита от ленивых».
- Managed-провайдеры с DRM: Cloudflare Stream (дёшево), Mux (лучший DX), Bunny, Vimeo Enterprise.
- Слои: сегментный стриминг → подписанные URL с TTL → ограничение по домену → forensic watermark → DRM.
- Полный захват экрана предотвратить нельзя в принципе — только повышать стоимость взлома.

## 10. Домен — шортлист (брейншторм 2026-05-30)

Ищем абстрактный домен-хак (имя+зона = одно слово), основной домен под self-care/meditation/training.

**Проверено по DNS (NXDOMAIN = свободен) и по базовой цене зоны:**
- Базовая `.ing` (Google Registry) = **~$10.81/год** register=renewal (Porkbun). Это для НЕпремиальных имён.
- ⚠️ `.ing` известна tiered-premium: короткие словарные слова часто premium (дорогой ежегодный renewal).
  Per-domain premium-цену автоматически вытащить НЕ удалось (GoDaddy/Namecheap/tld-list режут ботов 403;
  Gandi API за ключом). Проверять финалистов вручную: **Cloudflare Registrar** (at-cost, явно
  показывает premium) или Porkbun checkout.
